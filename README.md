# Yousician Growth Audit

**Live → https://eddieatadapty.github.io/yousician-flow-rebuild/**

Five ideas to turn more Yousician users into subscribers, each built into a clickable version of Yousician's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Use the four answers you already collect | +10–20% CR to trial start |
| 02 | Let people hear Yousician listen before the price | +5–15% CR to trial start |
| 03 | Put your proof where people decide | +5–10% CR to trial start |
| 04 | Make the yearly saving impossible to miss | +10–15% ARPU, from annual mix |
| 05 | Catch the people who close the paywall | +10–15% ARPU, from people who said no |

Every price, rating and feature comes from Yousician's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Yousician. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
